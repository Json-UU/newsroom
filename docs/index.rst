The Newsroom documentation
==========================

The Newsroom is a Django news platform. Journalists write articles and
newsletters, either independently or for a publisher. Editors review and
approve them. Readers subscribe to publishers and journalists and receive
approved stories in their feed and by email. A token-authenticated REST API
exposes the same content.
